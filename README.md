# 人生のゴール地点 投票アプリ

あなたの人生でいちばん目指したいゴール地点を選んで投票するアプリです。

## 特徴

- 4つのゴール選択肢から投票可能
- リアルタイムで投票結果を表示
- SQLite を使用してデータを永続化
- 投票リセット機能付き
- レスポンシブデザイン

## 選択肢

1. **家族との幸せな生活**
2. **世界を旅する自由**
3. **自分の好きな仕事で成功**
4. **心身ともに健康で充実した暮らし**

## セットアップ

```bash
# 依存パッケージをインストール
cd 3.0
npm install
```

## 実行

```bash
# サーバーを起動
npm start
```

ブラウザで `http://localhost:3000` にアクセスしてください。

## 技術スタック

- **フロントエンド**: HTML, CSS, JavaScript
- **バックエンド**: Node.js, Express
- **データベース**: SQLite 3

## API エンドポイント

- `GET /` - index.html を配信
- `POST /vote` - 投票を送信
  - リクエスト: `{ "option": "family" }`
- `GET /votes` - 投票結果を取得（JSON）
- `DELETE /votes` - すべての投票を削除
